# Occurra

AI-powered Occupancy Intelligence System using YOLO11 and ByteTrack.

## Features
- Real-time person detection
- Occupancy analytics
- Heatmap generation
- Zone-wise statistics
- Crowd insights dashboard
- React frontend
- FastAPI backend

## Tech Stack
- React.js
- FastAPI
- Python
- OpenCV
- YOLO11
- ByteTrack

## Project Structure
backend/
frontend/

## Installation

### Backend
cd backend
pip install -r requirements.txt
python main.py

### Frontend
cd frontend
npm install
npm run dev
